# Demo tooling

| Path | What |
|------|------|
| `api-examples/` | Postman collection + curl samples (`BASE_URL`, `API_KEY` placeholders) |
| `srm-import/` | Offline TrustLedger SRM demo import (CSVs, EXIF images, `import_script.py`) |
| `trustledger-srm-demo.zip` | Import pack zipped for handoff |

Do not run `--run` against production. Staging only with a human-scoped API key.
