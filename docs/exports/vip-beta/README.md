# Operator note — VIP beta terms v2 (Ibrahima feedback)

## What changed and why

VIP tester **Ibrahima** declined v1 because:

1. Terms appeared to require **real client / beneficiary data** → confidentiality + POPIA conflict.  
2. Confidentiality covered ownership/disclaimer but **not** Chibase use, access, deletion, or protection.  
3. **8 weeks active use + periodic feedback** exceeded available time.

## Response posture (locked for all VIP betas)

- Testing with **mock / anonymised / public / historical** data is first-class and sufficient.  
- Spell out: isolation, who can access, no sale, **no external model training**, purge on request after access ends.  
- Time is **flexible** — casual look-through is enough; no hours quota.

Canonical text: `BETA_TESTING_TERMS_OF_USE_v2.md` (paste to Canva letterhead).

## Ops checklist when sending v2

1. Replace the old Canva PDF with v2 wording.  
2. Email the tester: acknowledge the three points; attach v2; offer flexible window.  
3. Do **not** pressure live client data in onboarding calls or the setup wizard.  
4. If they still decline: keep the relationship warm; optional later re-invite with lighter “view-only walkthrough” (no data entry).
