# TrustLedger SRM — Live Showcase Demo Plan

**Audience:** Legal / consortium partners (e.g. Inlexso) evaluating TrustLedger for DFI-linked infrastructure bids (e.g. DBSA NILF / RFP-style packages).  
**Product:** [trustledger.co.za](https://trustledger.co.za) · **Cloud SoT:** TrustLedger Cloud  
**Purpose:** Prove the platform **in action** — not slides. Show that engagement, grievance, commitments, and reports form one defensible trail.  
**Voice:** Trust, auditability, Social Licence to Build™ (ADR-039). Do not name stack vendors in the room.

> **Integrity:** Do **not** use the retired public sample `/demo`. Showcase in a **seeded trial or live Project/Institutional workspace** with illustrative programme data. Never present fictional `INC-*` bleed as the prospect’s matter.

## 4. Objection handling

| Objection | Counter |
|-----------|---------|
| Why not HubSpot / Salesforce? | Sales CRMs optimise pipelines. This desk’s unit of work is **project + case + commitment** for wards, traditional authorities, and DFI monitoring — not deal stages. |
| We have SharePoint / Teams | Folders store files; they don’t enforce case state, ownership, SLA, or linked commitments. |
| Is it blockchain-immutable? | We sell **operational** defensibility: attributed actions, evidence on the case, human-applied AI, exportable packs — what panels can inspect. |
| Logging creates liability | Not logging creates liability. Structured, Owner-controlled logging with review before report circulation manages it. |
| Can we be live before submission? | Yes as named implementation tool: pilot workspace + Owner + field seats on one corridor. |
| POPIA / residency | Explicit seats; locked field desks; purpose is programme social performance, not adtech. |
| Facilitators won’t adopt | They already capture — in the wrong places. One desk cuts re-typing into month-end packs. |
| Price vs Excel | Excel is free until a stoppage or a failed monitoring visit. |
