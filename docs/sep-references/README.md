# SEP generation — logged reference documents

These two PDFs are the **mandatory methodological baseline** for the TrustLedger SRM Social Engagement & Participation (SEP) module. The generator must cite them and must not invent methods, processes, statutes, case studies, or sequences that are not grounded in them plus the uploaded tender.

| File | Role |
|------|------|
| `TrustLedger_SEP_Generation_Specification_v1.0.pdf` | Generation specification (tender-grounded analysis, no fabrication, 25-section structure, QA tests, method selection). |
| `Reference_Framework_for_Participatory_Social_Engagement_Methodologies.pdf` | PRA / PLA / CBPR library, inclusion, evidence, and the rule that **no single methodology is prescribed for every project**. |

Canonical citation helpers live in `src/data/sepCanon.ts`. Literature beyond Specification s.25 is not added.

**Rules the engine must keep:**

1. Facts come from the tender or an explicit client brief. Missing items are TBC.
2. Each assignment selects methods and an activity sequence from its classification (sector, displacement, research intensity, duration). A relocation census/host-consent calendar is not copied onto a municipal road upgrade.
3. The implementing organisation is the SRM workspace / appointed entity. Do not default to a consulting-firm brand.
